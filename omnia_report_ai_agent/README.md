# Omnia Report AI Agent

## Overview

`omnia_report_ai_agent` provides an **AI Agentic reporting Feature**. Users can print report with provide a brief command and instructions, and let a LLM generate a formatted Qweb PDF report. The report can be previewed inside printed.

## Features

- Provide AI Tool like Anthropic, OpenAI, Google Gemini or Groq providers.
- Automatic model fetching.
- Action Wizard with context target model/record IDs, command, instructions, and attachments.
- Live preview of generated HTML inside an iframe.
- Export to PDF.
- Fallback handling when a model becomes unavailable.
